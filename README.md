# 🛡️ SimplePass Manager

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Manifest V3](https://img.shields.io/badge/Chrome%20Extension-Manifest%20V3-success.svg)](src/manifest.json)
[![Encryption](https://img.shields.io/badge/Encryption-AES--256--GCM-cyan.svg)](src/core/crypto.js)

**SimplePass Manager** — современный, быстрый и безопасный Open-Source менеджер паролей для Google Chrome, Chromium, Brave, Arc и Edge. Работает прямо в нативной боковой панели браузера (Chrome Side Panel), обеспечивает военный уровень шифрования данных (**AES-256-GCM**) и предоставляет удобный интерфейс с автозаполнением, генератором паролей и поддержкой классического формата UNIX `pass`.

---

## ✨ Основные возможности

- 🔒 **Военный уровень безопасности**: шифрование на стороне клиента через стандарт W3C **Web Cryptography API**:
  - Алгоритм: **AES-256-GCM** (аутентифицированное шифрование).
  - Деривация ключа: **PBKDF2** с хэшем **SHA-256** и **600 000 итераций** (в соответствии со стандартами OWASP).
  - Уникальная 128-битная соль и 96-битный случайный вектор инициализации (IV) для каждой операции шифрования.
  - Мастер-пароль хранится исключительно в оперативной памяти во время сессии и **никогда не сохраняется на диск**.
- 🎨 **Премиальный интерфейс боковой панели (Side Panel)**:
  - Открывается по клику на иконку или через шорткат в боковой панели Chrome, не закрываясь при переходе между вкладками.
  - Тёмная стеклянная тема (Dark Glassmorphism) в эргономичном стиле.
  - Автоматическое определение текущего домена вкладки и вывод релевантных паролей.
- ⚡ **Интерактивное автозаполнение**:
  - Заполнение логина и пароля на активной странице в 1 клик.
  - Быстрое копирование логина или пароля с автоматической очисткой буфера обмена через 30 секунд.
- 🎲 **Криптографический генератор паролей**:
  - Настройка длины (8–64 символа) и наборов символов (A-Z, a-z, 0-9, спецсимволы).
  - Исключение неоднозначных символов (`0`, `O`, `1`, `l`, `|`).
  - Анализатор энтропии и надёжности в реальном времени.
- 🔄 **Совместимость с UNIX `pass` и резервные копии**:
  - Экспорт и импорт зашифрованных бэкапов в JSON.
  - Экспорт в стандартный формат консольного менеджера `pass` (`password-store`) для лёгкой миграции.
- 🌐 **100% автономность и приватность**:
  - Никаких внешних серверов, телеметрии или трекеров. Все данные хранятся локально в `chrome.storage.local`.

## 🚀 Быстрый старт (Установка за 1 минуту)

### Вариант 1. Установка из готовой сборки (Для пользователей)

1. Скачайте репозиторий или готовый архив проекта.
2. Откройте в браузере страницу управления расширениями:
   ```text
   chrome://extensions/
   ```
3. В правом верхнем углу включите переключатель **«Режим разработчика»** (Developer mode).
4. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) в левом верхнем углу.
5. Выберите папку `dist` (или корневую папку проекта после сборки).
6. Закрепите иконку SimplePass на панели браузера — готово!

---

### Вариант 2. Сборка из исходников (Для разработчиков)

Требования: [Node.js](https://nodejs.org/) v18+ и npm / pnpm.

```bash
# 1. Клонировать репозиторий
git clone https://github.com/your-username/SimplePassManager.git
cd SimplePassManager

# 2. Установить зависимости
npm install

# 3. Собрать проект
npm run build

# Либо запустить сборку в режиме отслеживания изменений (hot-rebuild):
npm run dev

# Создать zip-архив для публикации в Chrome Web Store:
npm run pack
```

## 🔐 Модель безопасности

1. **Zero-Knowledge**: Ваш мастер-пароль известен только вам. Никто (включая разработчиков расширения) не имеет технической возможности расшифровать ваши данные без знания мастер-пароля.
2. **Аутентифицированное шифрование**: AES-GCM предотвращает атаки типа "бит-флиппинг" и гарантирует целостность: любая модификация или повреждение зашифрованного файла немедленно вызовет отказ расшифровки.
3. **Безопасность буфера обмена**: При копировании пароля система автоматически очищает буфер через 30 секунд.
4. **Автоблокировка**: Настраиваемый тайм-аут блокировки хранилища при отсутствии активности.
