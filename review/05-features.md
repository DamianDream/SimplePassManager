## F3. Аудит здоровья паролей (Password Health) — [ВЫПОЛНЕНО ✅]

Реализовано в отдельной вкладке бокового меню «Безопасность (экспериментально)»:
- Выделенная вкладка с иконкой щита `iShield` в Drawer-меню.
- Быстрая кнопка «Быстрый аудит» (`#sp-btn-run-audit`) с расчётом индекса здоровья хранилища (0–100%) и выводом отчёта (проверено, повторы, слабые, устаревшие, надёжные).
- Поиск по паролям/сайтам и фильтрация по тегам / категориям.
- Фильтры по степени риска: «Все», «Повторы», «Слабые», «Устаревшие», «Надёжные».
- Интерактивная легенда цветовых обозначений статусов (🔴 дубликаты, 🟠 слабые, 🟡 устаревшие, 🟢 надёжные).
- Быстрый переход к смене пароля для каждой проблемной записи.
- 100% приватность: вычисление строго локально в памяти без сетевых запросов.
- Покрыто unit-тестом №40 и полной локализацией на 8 языков (все 361 ключ).

## F4. Корзина и история записей — [ВЫПОЛНЕНО ✅]

- Soft-delete: записи переносятся в `vault.trash[]` с меткой времени `deletedAt`.
- Автоочистка: корзина автоматически очищает элементы старше 30 дней при нормализации/разблокировке хранилища.
- Управление корзиной: раздел в Настройках со счётчиком, восстановлением одной кнопкой, окончательным удалением и полной очисткой.
- История паролей (`passwordHistory` до 5 последних версий с датами): сохраняется при смене пароля записи, доступна в форме редактирования с возможностью копирования и подстановки старого пароля; совместима с экспортом Bitwarden.
- Покрыто unit-тестами (тест №39) и локализацией на 8 языков (все 333 ключа).

## F6. Импорт из других менеджеров

Расширить unified-импорт детекцией форматов: Chrome/Edge CSV (`name,url,username,password`), LastPass CSV, 1Password CSV, KeePass XML (опционально). Детекция по заголовку, маппинг колонок, предпросмотр первых 5 строк перед импортом, отчёт (B7в).

## F7. zxcvbn вместо наивного скоринга

Подключить `@zxcvbn-ts/core` + `@zxcvbn-ts/language-en` (локальный bundle, без сети) и заменить `evaluatePasswordStrength` в генераторе, форме записи и установке мастер-пароля (H6). Старую функцию удалить.

## F8. Генератор парольных фраз

Режим «фраза»: 4–8 слов из `RECOVERY_WORDLIST` (или расширенного словаря H5) с разделителем на выбор и опциональной цифрой — для мастер-паролей и сайтов, где удобнее запоминаемое.

## F9. Синхронизация между устройствами (этап 1 — файловая)

Автоэкспорт зашифрованного конверта целиком в файл по расписанию недоступен расширению; реализовать: кнопка «Экспорт зашифрованного бэкапа» (H7в) + напоминание раз в N дней «сделайте бэкап» + импорт с merge-стратегией (по `item.id` + `updatedAt`, конфликт → обе копии с пометкой). Этап 2 (отдельное решение, не делать без отдельного задания): sync через `chrome.storage.sync` невозможен по размеру; рассматривать WebDAV/папку пользователя через `chrome.downloads`.

## F10. Поддержка нескольких URL на запись

`item.urls: string[]` (миграция: `url → urls[0]`, поле `url` сохранять для обратной совместимости экспорта). Матчинг C3 проверяет все.

## F11. Автозаполнение: устойчивость на реальных сайтах

Доработать `content.js`: (а) двухшаговые логины (Google: только username → после навигации пароль; если поля пароля нет, заполнить username и вернуть `{partial:true}`, UI предложит «заполнить пароль» на следующем экране); (б) поиск внутри открытых shadow DOM (рекурсивный обход `element.shadowRoot`); (в) `all_frames: true` при инжекте с проверкой origin фрейма == origin top (иначе пропуск — анти-фишинг); (г) выставлять значение через нативный сеттер для React-форм: `Object.getOwnPropertyDescriptor(HTMLInputElement.prototype,'value').set.call(el, value)` перед dispatch `input`.

## F12. Экспорт/импорт настроек и статистика

Экспорт конфига (темы, категории, цвета) отдельно от паролей; экран «О хранилище»: число записей, размер, дата последнего бэкапа.
