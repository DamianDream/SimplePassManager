# 06. Рекомендации UI/UX (P2)

---

## U1. Рефакторинг монолита sidepanel (предусловие остальных U-задач) — [ВЫПОЛНЕНО ✅]

**Где:** `src/sidepanel/index.js` — декомпозирован на модули, внедрён ADR-комментарий, скоупированный рендеринг и делегирование событий.

**Проблемы (устранены):** потеря фокуса и позиции курсора при вводе устранена (поиск обновляет исключительно `#sp-vault-cards-container`, не затрагивая DOM инпута); скролл списка сохраняется при операциях; ни один файл не превышает лимит в 800 строк.

**Что сделано:**
1. Разнесено по чистым модулям: `views/auth.js`, `views/vault-list.js`, `views/item-form.js`, `views/generator.js`, `views/settings.js`, `views/modals.js`, `handlers/*.js` (`auth-handlers.js`, `header-handlers.js`, `vault-handlers.js`, `item-form-handlers.js`, `generator-handlers.js`, `settings-handlers.js`, `settings-tag-handlers.js`, `modal-handlers.js`), `render-utils.js` (`escapeHtml`, `showToast`, `showFieldError`), `panel-state.js` и `vault-operations.js`.
2. Скоупированный рендеринг: постоянный каркас скелета монтируется один раз; фильтрация поиска точечно патчит только контейнер карточек `#sp-vault-cards-container`; поля ввода не пересоздаются.
3. Делегирование событий и ликвидация утечек памяти: единственный глобальный `click`-листенер вне элементов, контекстные делегаты в обработчиках.
4. Зафиксирован ADR в заголовке `src/sidepanel/index.js` (vanilla modular architecture с нативным MV3 CSP, нулевыми внешними зависимостями и быстрым стартом).
5. Строгий лимит строк: каждый файл строго < 800 строк (все файлы от 63 до 736 строк).

**Критерии приёмки:** ввод в поиск не теряет фокус (выполнено); скролл списка сохраняется при операциях (выполнено); ни один файл > 800 строк (выполнено: макс 736 строк); тесты 38/38 и 316/316 i18n пройдены, сборка dist/ и zip валидна.

## U2. Онбординг и экран создания хранилища

Трёхшаговый мастер: 1) приветствие + что такое мастер-пароль («не восстанавливается, запишите»); 2) создание пароля с индикатором силы (H6) и чек-листом требований, обновляющимся на лету; 3) показ 12 слов с принудительным подтверждением (ввести 3 случайных слова из фразы, как в крипто-кошельках) — текущая модалка позволяет закрыть, не сохранив фразу. Кнопки «копировать»/«скачать» оставить.

## U3. Экран разблокировки

(а) Автофокус на поле пароля; (б) показ/скрытие пароля глазком; (в) индикатор Caps Lock (`KeyboardEvent.getModifierState('CapsLock')`); (г) при задержке после неверных попыток (C6) — обратный отсчёт; (д) имя активного профиля хранилища и переключатель профилей прямо на экране; (е) индикатор процесса расшифровки (PBKDF2 занимает заметное время — spinner на кнопке).

## U4. Замена нативных confirm()/alert()

**Где:** `deleteItem` использует `confirm()` (index.js:744), стилистически выбивается и не локализуется едино. Сделать переиспользуемый модал (`views/modals.js`): заголовок, текст, danger-кнопка; с focus-trap и закрытием по Esc. Для удаления записи — undo-тост «Удалено. Отменить (5 c)» вместо confirm (вместе с F4-корзиной).

## U5. Доступность (a11y)

(а) `aria-label` на всех icon-only кнопках (копировать/глазок/удалить); (б) роли и `aria-expanded` на кастомных селектах/дропдаунах; (в) полная клавиатурная навигация списка (стрелки + Enter = открыть, Ctrl+C = копировать пароль выбранной записи); (г) видимый `:focus-visible` стиль; (д) контраст текста `--text-dim` на фоне ≥ 4.5:1 в обеих темах (проверить токены в `sidepanel.css`); (е) `prefers-reduced-motion` — отключать анимации.

## U6. Тема по системе

Третье значение темы `system` (по умолчанию для новых пользователей): `matchMedia('(prefers-color-scheme: dark)')` + подписка на изменение.

## U7. Обратная связь при копировании

После копирования пароля: тост с таймером-прогрессом «Очистится через 30 с» и кнопкой «Очистить сейчас»; иконка на карточке меняется на галочку на 1.5 с. Копирование логина — без таймера очистки (не секрет), подпись различать.

## U8. Список записей

(а) Виртуализация при >100 записей (простая оконная отрисовка, без библиотек) — сейчас рендерится весь список; (б) сортировка (по имени/дате/использованию) и группировка по тегу; (в) подсветка совпадений поискового запроса; (г) счётчик «N записей» в шапке; (д) pull-состояния: скелетоны при первой загрузке, пустые состояния с иллюстрацией и CTA (есть частично — унифицировать).

## U9. Форма записи

(а) Автоподстановка title из domain при вводе URL; (б) кнопка «сгенерировать» прямо в поле пароля (сейчас генератор — отдельная вкладка; добавить inline-попап с длиной и кнопкой «перегенерировать»); (в) индикатор силы пароля под полем; (г) предупреждение о несохранённых изменениях при уходе с формы; (д) видимая кнопка «показать пароль» и в режиме просмотра.

## U10. Настройки

(а) Поиск по настройкам уже есть — добавить якоря-секции и счётчик результатов; (б) опасные действия (удалить хранилище, удалить профиль) — в отдельную секцию «Danger zone» с красной рамкой; (в) у каждого тумблера приватности (favicon-сервисы, tabs-permission) — подпись, какие данные куда уходят; (г) показать текущее состояние сессии: «Разблокировано до HH:MM» + кнопка «Заблокировать сейчас» в шапке.

## U11. Статус интеграции pass CLI

Единый экран состояния: host установлен/нет, pass/gpg найдены/нет (данные уже приходят из `handle_check`) — с конкретными командами установки для ОС пользователя и кнопкой «проверить снова». Ошибки native messaging показывать человеческим текстом, а не сырой строкой Chrome.

## U12. Микро-полировка

(а) Иконка расширения: бейдж-замок на `chrome.action.setBadgeText` когда хранилище разблокировано (осознание состояния); (б) анимации открытия модалок ≤150 мс; (в) tooltips с задержкой 500 мс; (г) формат дат через `Intl.DateTimeFormat(currentLanguage)`; (д) единые радиусы/отступы — вынести в CSS-токены.
