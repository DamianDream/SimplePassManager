# 07. Страница скачивания и установки (сайт дистрибуции)

Цель: одностраничный статический сайт, с которого расширение легко устанавливается в большинство браузеров. Важно понимать ограничение платформы: **Chrome/Edge/Opera/Brave не позволяют устанавливать .crx вне магазинов** — для них страница ведёт в магазин; «скачать zip» остаётся для разработчиков/энтузиастов (load unpacked) и как fallback до публикации.

## D1. Технология и структура

- Статический сайт без фреймворка (или Astro, если нужен i18n из коробки): каталог `site/` в репозитории.
- Хостинг: GitHub Pages (бесплатно, деплой через Actions) или Cloudflare Pages. Домен — по желанию владельца.
- Страницы: `index.html` (лендинг + установка), `privacy.html` (из W3), `changelog.html` (генерировать из git-тегов).
- Языки: EN (основной) + RU; переключатель, автодетект по `navigator.language`.

## D2. Логика «умной» кнопки установки

JS-детект браузера (по `navigator.userAgentData.brands`, fallback на UA):
| Браузер | Действие кнопки |
|---|---|
| Chrome, Brave, Vivaldi, Arc | ссылка на листинг Chrome Web Store |
| Edge | листинг Edge Add-ons (или CWS, пока Edge-листинга нет) |
| Opera | addons.opera.com (или CWS с инструкцией «Install Chrome Extensions») |
| Firefox | листинг AMO (появится после сборки `build:firefox`, W8); до того — блок «Firefox скоро» |
| Safari / мобильные | блок «не поддерживается», ссылка на roadmap |

Под кнопкой — аккордеон «Другие способы установки»: скачивание `simplepass-chrome-vX.Y.Z.zip` из GitHub Releases + пошаговая инструкция load unpacked со скриншотами (текст уже есть в README — перенести и перевести).

## D3. Контент лендинга

Hero (иконка, слоган, кнопка установки), 4–6 карточек фич (шифрование локально, боковая панель, автозаполнение, генератор, pass CLI, open source), скриншоты из W5, секция «Безопасность» (честное описание схемы: AES-256-GCM, PBKDF2, локальное хранение — после фиксов C1/C2), FAQ (что будет при утере пароля; где хранятся данные; как сделать бэкап), ссылки на GitHub/issues/privacy. Никаких счётчиков/аналитики третьих сторон (иначе придётся менять privacy policy); при необходимости — самостоятельный Cloudflare Web Analytics без cookie.

## D4. Автоматизация релизов

GitHub Actions `release.yml`: на тег `v*` — build, тесты, сборка `simplepass-chrome-vX.Y.Z.zip` и `simplepass-firefox-vX.Y.Z.zip`, создание GitHub Release с артефактами; сайт при деплое подтягивает ссылку «последний релиз» через `https://github.com/<owner>/<repo>/releases/latest/download/<file>` (постоянный URL, API не нужен).

## D5. Инструкция для native host на сайте

Отдельная секция «Интеграция с pass CLI»: требования (macOS/Linux, pass, gpg), команда установки one-liner (`curl -fsSL <raw-url>/native-host/install.sh | bash -s -- <EXTENSION_ID>` — только после фикса C4), кнопка копирования, предупреждение о правах доступа хоста к `~/.password-store`, инструкция удаления (`uninstall.sh`).

## D6. Критерии приёмки

- Открытие страницы в Chrome/Firefox/Edge показывает корректную кнопку для каждого браузера.
- Lighthouse: Performance/A11y/Best Practices/SEO ≥ 90.
- Страница работает без JS (кнопка деградирует до списка всех магазинов).
- Ссылка на privacy policy доступна с любой страницы (требование W3).
